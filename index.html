About

Morph

Morph is a free, browser-based file studio. Prepare images and PDFs for print, convert common image formats, compress images to a target size, or run local vectorization, background-removal, and upscaling tools. Files stay on your device; no paid services are used.

File conversion

Convert browser-readable raster images to PNG, JPG, WebP, TIFF, BMP, or PDF. PNG, TIFF, and generated PDF preserve decoded pixel values; JPG and WebP use lossy encoding. Digital PDF uses 96 DPI sizing and Print PDF uses 300 DPI without resizing pixels. Other file types can be copied byte-for-byte, but require a format-specific engine to convert.

Image tools

Vectorize traces an image into SVG shapes. Background removal makes edge-connected pixels matching a chosen flat color transparent. Upscaling uses browser interpolation at 2× or 4×; it cannot invent image detail. The free ImageTracer library loads on demand, while your image stays local.

Compression

Compression accepts PDFs and browser-readable images, targeting a size or percentage reduction. PDF pages are rasterized at up to 150 DPI for compressed PDF output; multi-page PDF to PNG creates a ZIP of lossless page images. JPG and WebP output are lossy. Target sizes are best-effort and the original file is unchanged.

PDF input

In Print-ready, uploaded PDFs are rasterized page-by-page in your browser (via pdf.js), then treated like images for layout and export. Vector content, live text, and layers are flattened, and fitting to page settings can resample pixels. To preserve an existing PDF exactly, use Convert and choose Original file.

Color modes

Match Source (default) makes no color conversion at all: if the uploaded PNG or JPEG has an embedded ICC profile, that exact profile is carried through and embedded directly in the exported file's image data; if none is found, the export is tagged sRGB, which is what your browser used to decode the pixels. This is the mode to use if you don't want Morph to touch your color in any way.

RGB exports DeviceRGB pixel data with your chosen output profile (sRGB, Adobe RGB, or your own uploaded ICC file) embedded directly on the image, so Illustrator, CorelDRAW, Acrobat, and other ICC-aware apps display it exactly as tagged instead of reinterpreting it through their own default working space — which is what caused unexpected color shifts before.

CMYK converts for press output. Browsers have no built-in color-management engine, so this conversion is a documented device approximation (proper black generation, not a naive channel inversion) — not a true ICC-managed transform. Named output profiles (SWOP v2, FOGRA39) tag the export with the correct industry-standard identifier but are only embedded as real ICC binaries if you upload your own ICC file — in which case it's embedded verbatim on the image, not just referenced.

Output quality

Print-ready PDF and TIFF store rendered pixel data with lossless Flate compression, never JPEG. Layout scaling, color conversion, and rasterizing a PDF can still change source content. The Convert workflow keeps PNG, TIFF, and generated PDF pixel data lossless; JPG and WebP are intentionally lossy.

PDF/X-1a

When CMYK is selected, PDF exports are hand-written to be structurally compliant with PDF/X-1a — CMYK-only color, embedded OutputIntent, no transparency. This is best-effort compliance; it is not run through a certified preflight validator. RGB and Match Source exports are standard, widely compatible PDFs (not PDF/X, since PDF/X-1a requires CMYK) built with the same plain cross-reference table structure for maximum compatibility with Illustrator, CorelDRAW, and other PDF readers.
