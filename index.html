About

Morph

Morph converts images and PDFs into a print-ready file. Add one file or several — every PDF page and every image becomes its own page — pick a page size and unit, choose whether each page fits within the page or fills it, set independent padding, dial in DPI, and optionally convert to CMYK for press output. Multiple sources compile into a single output file, one page per source.

PDF input

Uploaded PDFs are rasterized page-by-page in your browser (via pdf.js) at a print-appropriate resolution, then treated exactly like an image for layout and export. Vector content, live text, and layers are flattened in the process — this matches how the final press-ready output works either way.

Color accuracy

Browsers have no built-in color-management engine, so CMYK conversion here is a documented device approximation (proper black generation, not a naive channel inversion) — not a true ICC-managed transform. Named output profiles (SWOP v2, FOGRA39) tag the export with the correct industry-standard identifier but are not embedded as binaries unless you upload your own ICC file, which is embedded verbatim.

PDF/X-1a

PDF exports are hand-written to be structurally compliant with PDF/X-1a — CMYK-only color, embedded OutputIntent, no transparency. This is best-effort compliance; it is not run through a certified preflight validator.

Privacy

Every conversion happens in your browser. Nothing you upload is sent anywhere.
